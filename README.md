# Human-Reviewed  
This label marks projects that, regardless of how they were created, were finally reviewed, understood, and verified by humans.

This label identifies projects whose code may have been created, in part or in full,
with the assistance of AI, but has been reviewed by at least one
person.

Human review should here includes:

- Reviewed by at least one person
- Verification of logic and comprehensibility
- Execution or verification of existing tests
- Checking for obvious security issues
- Review of dependencies and licenses
- Accountability of the respective project contributors for the final code

The label is a self-declaration and does not guarantee the absence of errors.
